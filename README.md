# Advanced CSS3 & Responsive Architecture

## Thiranex Internship – Task 2

A modern, accessible and fully responsive portfolio demonstrating:

- CSS Grid for two-dimensional page layouts
- Flexbox for component alignment
- Mobile-first responsive media queries
- CSS custom properties (variables)
- Light/dark mode with localStorage
- Semantic HTML5 structure
- Keyboard-friendly focus states
- Responsive typography with `clamp()`
- Reduced-motion support
- Accessible skip navigation and form labels

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload all project files.
3. Go to Settings → Pages.
4. Select `main` branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.
